Benchmark overview

One focused hardware-generation task

Each case defines one semantic top module and a complete behavioral specification. Case names describe the design instead of exposing source-corpus identifiers.

01 / Input

Read a natural-language specification

The evaluated model receives only spec.txt, including the exact module name and interface.

02 / Output

Implement the complete RTL module

The submission is one synthesizable Verilog implementation matching the required interface and behavior.

03 / Score

Prove functional equivalence

JasperGold SEC compares the submission with a model-hidden reference implementation.
