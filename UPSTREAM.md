# Upstream provenance

ScaleBench was selected from the [RTL-PP dataset](https://huggingface.co/datasets/makyash/RTL-PP):

- Dataset: `makyash/RTL-PP`
- Upstream fields used: RTL `code` and natural-language `instruction`
- Selection: designs admitted by the CorrectRTL formal-equivalence preparation flow
- Upstream dataset license declaration: MIT

ScaleBench adds the 200-design selection, curated specifications, semantic task identifiers, normalized case packages, reference metadata, and formal-equivalence collateral. Users redistributing derivative HDL should independently confirm any source-specific notice or attribution requirements.
