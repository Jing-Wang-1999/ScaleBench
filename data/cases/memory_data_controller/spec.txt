The purpose of the `memory_data_controller` Verilog module is to process input data and control the output display segments based on various selection and clock signals. The module reads a 16-bit input data and transforms it into Binary Coded Decimal (BCD) format for display, utilizing selection signals to determine scaling and specific display outputs.

1. **Primary Function:** The `memory_data_controller` facilitates display control by converting input data into BCD format and routing appropriate segments to output registers based on the `display_sel` and `sel` signals.

2. **Key Control Flow:**
   - When `display_sel` is high, the display outputs (`D1`, `D2`, `D3`, and `D4`) are directly assigned from the BCD converted data.
   - When `display_sel` is low, the display outputs show a mix of zero and parts of the original input data.
   - The `sel` signal decides between direct or scaled data conversion.

3. **Key Signal and Data Interactions:**
   - The module converts the binary input data into an unsigned format (`unsigned_data`) to handle potential sign bits.
   - Depending on the `sel` value, the data may undergo scaling, primarily a multiplication by 10 unless a specific case (binary inversion and offset) is chosen.
   - Once the data is prepared, it is converted into BCD format using an emulated `binary_to_bcd` function.
   - BCD values are then assigned to BCD buffer registers on clock edges (`clk` and `dclk`), and further used for output control based on `display_sel`.

Behavioral Clarifications:
- When sel==2'b11, the scaled value is computed as {4'b0000, (25 - (data - 25))} using the raw (possibly signed) data, not unsigned_data; the BCD sign indicator bcd[15:12] is set to 4'b1111 when data[15] is 1 and bcd[11:0] is nonzero, otherwise 4'b1010.
- When sel==2'b11, bcd[11:0] is {bcd_buf[7:0], 4'b1011}; for all other sel values bcd[11:0] equals bcd_buf[11:0].
- The binary_to_bcd function implements the double-dabble (shift-and-add-3) algorithm on the lower 16 bits only, producing a 16-bit BCD result.
