Implement a clocked data-to-display controller with four hexadecimal display digits.

Module Interface:
module memory_data_controller (
    clk,
    dclk,
    rst,
    display_sel,
    sel,
    data,
    D1,
    D2,
    D3,
    D4
);

Ports:
- `clk` is the rising-edge clock; `dclk` is a clock enable sampled on `clk`.
- `rst` is an asynchronous active-high reset.
- `display_sel` selects the formatted display or raw input nibbles.
- `sel` is a 2-bit scaling selector and `data` is a 16-bit input.
- `D1` through `D4` are 4-bit combinational outputs.

Data preparation:
- Define `unsigned_data` as the 16-bit two's-complement magnitude of `data`: use `(~data) + 1'b1` when `data[15]` is set, otherwise use `data`.
- When `sel != 2'b11`, multiply `unsigned_data` by 10, retain the low 20 bits, and use bits `[19:10]` as a 10-bit value zero-extended to 16 bits.
- When `sel == 2'b11`, the 16-bit scaled value is the modulo-65536 result of `16'd50 - data`.

BCD register:
- On `rst`, set `bcd_buf` to zero.
- Otherwise, on a rising edge of `clk` with `dclk` asserted, store `binary_to_bcd(scaled_value)` in `bcd_buf`.
- `binary_to_bcd` uses a 32-bit shift register initialized as `{16'b0, binary}`. For 16 iterations, add 3 only to nibbles `[27:24]` and `[31:28]` when that nibble is at least 5, then shift left once. Return bits `[31:16]`.

Display formatting:
- When `sel == 2'b11`, set `bcd[11:0]` to `{bcd_buf[7:0], 4'b1011}`; otherwise use `bcd_buf[11:0]`.
- Set `bcd[15:12]` to `4'b1111` when `data[15]` is set and `bcd[11:0]` is nonzero; otherwise set it to `4'b1010`.
- When `display_sel` is high, drive `D1`, `D2`, `D3`, and `D4` from `bcd[15:12]`, `bcd[11:8]`, `bcd[7:4]`, and `bcd[3:0]`.
- When `display_sel` is low, drive `D1=0`, `D2=data[15:12]`, `D3=data[11:8]`, and `D4=data[7:4]`.
