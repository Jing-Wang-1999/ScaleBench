Implement a synchronous 16384 x 32-bit byte-writeable instruction memory.

Module Interface:
module soc_instruction_memory_16kx32 (
    address,
    byteenable,
    chipselect,
    clk,
    clken,
    reset,
    write,
    writedata,
    readdata
);

Ports:
- `address` is a 14-bit word address.
- `byteenable` selects the four byte lanes, with bit 0 controlling `writedata[7:0]` and bit 3 controlling `writedata[31:24]`.
- `chipselect` and `write` jointly enable a write.
- `clk` is the rising-edge clock and `clken` enables memory operations.
- `reset` is an active-high synchronous reset.
- `writedata` and registered `readdata` are 32 bits wide.

Required behavior:
- On a rising edge with `reset` asserted, every address becomes logically zero and `readdata` becomes zero. Reset has priority over `clken`.
- When reset is deasserted and `clken` is low, all state holds.
- When reset is deasserted and `clken` is high, `readdata` captures the word stored at `address` before any write on that edge.
- A write occurs only when `chipselect && write` is true. Enabled byte lanes are replaced from `writedata`; disabled lanes retain their previous values.
- A location that has not been written since reset reads as `32'b0`. A write with no byte enables marks the location as written but leaves its value unchanged.

The implementation must be self-contained and must not read an external initialization file.
