The Verilog module acts as an AXI protocol bridge, interfacing between a slave AXI and a master AXI to pass data and control signals while ensuring protocol compliance.

### Primary Function:
The module facilitates data transfers and responses between an AXI slave interface and an AXI master interface using AXI protocol signals. It manages handshakes, address/data transfers, and response handling.

### Key Control Flow:
1. **Reset Handling:**
   - On reset (`aresetn`), all registers and outputs are initialized to ensure that no unintended data or state exists.

2. **AXI Handshakes:**
   - The module responds to various handshake signals (`awvalid`, `wvalid`, `bready`, `arvalid`, `rready`) by setting corresponding ready/valid signals to establish successful data and address transfers.

### Important Data Processing and Signal Interactions:
1. **Write Address Channel:**
   - Slave signals (`s_axi_awid`, `s_axi_awaddr`, `s_axi_awlen`, etc.) are directly assigned to corresponding master signals (`m_axi_awid`, `m_axi_awaddr`, `m_axi_awlen`, etc.) to transmit write address information.
   - Handshake signal `s_axi_awready` is set based on `m_axi_awready`.

2. **Write Data Channel:**
   - Data (`s_axi_wdata`, `s_axi_wstrb`, etc.) from the slave is passed to the master (`m_axi_wdata`, `m_axi_wstrb`, etc.).
   - `s_axi_wready` is controlled using `m_axi_wready`.

3. **Write Response Channel:**
   - Write response signals from master (`m_axi_bid`, `m_axi_bresp`, etc.) are propagated to the slave (`s_axi_bid`, `s_axi_bresp`, etc.).
   - Handshake signal `m_axi_bready` is influenced by `s_axi_bready`.

4. **Read Address Channel:**
   - Address signals and associated information from the slave (`s_axi_arid`, `s_axi_araddr`, etc.) are relayed to the master (`m_axi_arid`, `m_axi_araddr`, etc.).
   - Handshake ready signal `s_axi_arready` is driven by `m_axi_arready`.

5. **Read Data Channel:**
   - Data and response signals from the master (`m_axi_rid`, `m_axi_rdata`, `m_axi_rresp`, etc.) are transferred to the slave (`s_axi_rid`, `s_axi_rdata`, `s_axi_rresp`, etc.).
   - Handshake signal `m_axi_rready` is influenced by `s_axi_rready`.

### Instruction:
Create a Verilog module that bridges an AXI slave interface to an AXI master interface, enabling data and control signal transfers between them. Implement reset logic to initialize all registers. Establish handshake mechanisms to control signal readiness and valid states based on both slave and master protocol requirements. Ensure proper data, address, and response propagation across write and read channels, reflecting a fully compliant AXI geometry. Incorporate necessary state management to handle protocol-specific interactions and signal integrity.

Behavioral Clarifications:
- All signal transfers are registered (clocked on posedge aclk, active-low aresetn). Key widths: AXI ID is 16 bits, address is 40 bits, data is 32 bits, wstrb is 4 bits, user is 16 bits. All outputs reset to zero on aresetn=0; otherwise, slave-to-master and master-to-slave signals are registered pass-through each clock cycle.
