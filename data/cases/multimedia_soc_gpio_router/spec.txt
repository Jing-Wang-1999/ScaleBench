Implement `multimedia_soc_gpio_router` as a combinational board-interface
router with deterministic safe-idle values. This task does not model a DDR3,
Ethernet, USB, video, or storage controller.

The six `gpio_bd_i` inputs are routed to `gpio_bd_o[5:0]`, while
`gpio_bd_o[7:6]` are zero. All other input signals are intentionally ignored.

Use the following exact output policy:

- Drive `ddr3_a`, `ddr3_ba`, `ddr3_ck_p`, `ddr3_ck_n`, `ddr3_cke`,
  `ddr3_dm`, and `ddr3_odt` low. Drive `ddr3_reset_n`, `ddr3_cs_n`,
  `ddr3_ras_n`, `ddr3_cas_n`, and `ddr3_we_n` high. Release `ddr3_dq`,
  `ddr3_dqs_p`, and `ddr3_dqs_n` to high impedance.
- Drive the Ethernet transmit signals and `eth1_mdc` low, and release
  `eth1_mdio` to high impedance.
- Drive `sdio_clk` low and release `sdio_cmd` and `sdio_d`.
- Drive both SPI clocks and both MOSI outputs low. Drive `spim1_ss0` and
  `spi_csn` high.
- Drive `usb1_stp` low and release `usb1_d`.
- Hold the UART transmit line high and release `hps_conv_usb_n`.
- Drive all HDMI video outputs low and release both HDMI I2C lines.
- Drive `start_n` and `reset_n` high. Drive `sdp_convst` and `sdp_mclk` low.

The module contains no state and must not drive any port declared as an input.

Module Interface:
module multimedia_soc_gpio_router (
  input          sys_clk,

  output [14:0]  ddr3_a,
  output [2:0]   ddr3_ba,
  output         ddr3_reset_n,
  output         ddr3_ck_p,
  output         ddr3_ck_n,
  output         ddr3_cke,
  output         ddr3_cs_n,
  output         ddr3_ras_n,
  output         ddr3_cas_n,
  output         ddr3_we_n,
  inout  [31:0]  ddr3_dq,
  inout  [3:0]   ddr3_dqs_p,
  inout  [3:0]   ddr3_dqs_n,
  output [3:0]   ddr3_dm,
  output         ddr3_odt,
  input          ddr3_rzq,

  output         eth1_tx_clk,
  output         eth1_tx_ctl,
  output [3:0]   eth1_tx_d,
  input          eth1_rx_clk,
  input          eth1_rx_ctl,
  input  [3:0]   eth1_rx_d,
  output         eth1_mdc,
  inout          eth1_mdio,

  output         sdio_clk,
  inout          sdio_cmd,
  inout  [3:0]   sdio_d,

  output         spim1_ss0,
  output         spim1_clk,
  output         spim1_mosi,
  input          spim1_miso,

  input          usb1_clk,
  output         usb1_stp,
  input          usb1_dir,
  input          usb1_nxt,
  inout  [7:0]   usb1_d,

  input          uart0_rx,
  output         uart0_tx,
  inout          hps_conv_usb_n,

  output [7:0]   gpio_bd_o,
  input  [5:0]   gpio_bd_i,

  output         hdmi_out_clk,
  output         hdmi_vsync,
  output         hdmi_hsync,
  output         hdmi_data_e,
  output [23:0]  hdmi_data,

  inout          hdmi_i2c_scl,
  inout          hdmi_i2c_sda,

  input          adc_clk_in,
  input          adc_ready_in,
  input  [3:0]   adc_data_in,
  output         spi_csn,
  output         spi_clk,
  output         spi_mosi,
  input          spi_miso,
  output         start_n,
  output         sdp_convst,
  output         sdp_mclk,
  output         reset_n
);
