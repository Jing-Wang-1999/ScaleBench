Create a deterministic memory-mapped I/O and timer controller named `direct_irq_io_timer_controller` with the exact interface below.

```verilog
module direct_irq_io_timer_controller
(
    input        clk,
    input        clk7_en,
    input        clk7n_en,
    input        aen,
    input        rd,
    input        wr,
    input        reset,
    input  [3:0] rs,
    input  [7:0] data_in,
    output [7:0] data_out,
    input        tick,
    input        eclk,
    output       irq,
    input  [7:2] porta_in,
    output [3:0] porta_out,
    input  [7:0] portb_in,
    input        kms_level,
    input  [1:0] kbd_mouse_type,
    input  [7:0] kbd_mouse_data,
    output       freeze,
    input        hrtmon_en
);
```

All state uses the rising edge of `clk` and has a synchronous active-high `reset`. A bus read occurs when `aen && rd && !wr`; a bus write occurs when `aen && wr`. Reads outside an implemented address return zero, and `data_out` is zero when no read is active. `tick` and `eclk` are unused compatibility inputs.

Register map:

| `rs` | Read | Write |
|---|---|---|
| `0` | `{registered porta_in[7:2], porta_out[1:0]}` | Store `{data_in[7:6],data_in[1:0]}` in the four-bit port-A data register |
| `1` | `portb_in` | No effect |
| `2` | Port-A direction register | Port-A direction register |
| `3` | Port-B direction register | Port-B direction register |
| `4`,`5` | Timer-A low, high byte | Timer-A low, high byte |
| `6`,`7` | Timer-B low, high byte | Timer-B low, high byte |
| `8`,`9`,`A` | Timer-D low, middle, high byte | Timer-D low, middle, high byte |
| `C` | Serial-data register | Serial-data register |
| `D` | Eight-bit interrupt-control scratch register | Interrupt-control scratch register |

Sample `porta_in` whenever `clk7_en` is high. Reset both direction registers and the port-A data register to zero. Drive `porta_out[3:2] = (~direction[7:6]) | data[3:2]` and `porta_out[1:0] = (~direction[1:0]) | data[1:0]`.

Timers A and B are 16 bits and timer D is 24 bits. Reset all timers to zero. Whenever `clk7_en` is high, a selected byte write has priority; otherwise each timer increments by one modulo its width. Assert `irq` whenever timer A is `16'hffff`, timer B is `16'hffff`, timer D is `24'hffffff`, or the one-cycle keyboard/mouse strobe is active.

On reset, clear the sampled keyboard level, strobe, serial-data register, and `freeze`. On each `clk7n_en` cycle, update the sampled `kms_level` and pulse the strobe for one cycle when the level changed and `kbd_mouse_type == 2'b10`. When that strobe is observed on a `clk7_en` cycle, load the serial-data register with `~{kbd_mouse_data[6:0],kbd_mouse_data[7]}` and set `freeze` exactly when `hrtmon_en && kbd_mouse_data == 8'h5f`; otherwise preserve both values until another keyboard/mouse event or a bus write to the serial-data register.
