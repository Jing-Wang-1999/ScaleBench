Implement a stateful IMA-style ADPCM encoder.

Module Interface:
module adpcm_codec (
    input clk,
    input reset,
    input signed [15:0] x_in,
    output [3:0] y_out,
    output signed [15:0] p_out,
    output reg p_underflow,
    output reg p_overflow,
    output signed [7:0] i_out,
    output reg i_underflow,
    output reg i_overflow,
    output signed [15:0] err,
    output [14:0] sz_out,
    output s_out
);

State and reset:
- Maintain signed 16-bit registers `va`, `va_d`, and `valpred`, a 15-bit `step`, and a signed 8-bit `index`.
- On the rising edge of `clk` or the rising edge of `reset`, reset `va`, `va_d`, `step`, `index`, and `valpred` to zero when reset is asserted.
- Otherwise update simultaneously: `va_d <= va`, `va <= x_in`, `step <= step_table[next_index]`, `index <= next_index`, and `valpred <= next_prediction`.

Combinational encoding:
1. Compute the signed difference `diff = va - valpred`. Record whether it is negative and operate on its magnitude.
2. Start the prediction difference at `step/8`. If the magnitude is at least `step`, set delta bit 2, subtract `step`, and add `step`. If the remainder is at least `step/2`, set delta bit 1, subtract `step/2`, and add `step/2`. If the final remainder is at least `step/4`, set delta bit 0 and add `step/4`.
3. Add or subtract the prediction difference from `valpred` according to the sign. Clamp the result to the signed 16-bit range. Assert `p_overflow` or `p_underflow` when the corresponding clamp occurs.
4. Add the signed index-table entry selected by the 3-bit delta magnitude to `index`. Clamp the result to 0 through 88. Assert `i_underflow` or `i_overflow` when the corresponding clamp occurs.
5. Set `y_out` to the 3-bit delta magnitude with the sign in bit 3.

The signed 5-bit index adjustment table for codes 0 through 15 is:

```
-1, -1, -1, -1, 2, 4, 6, 8,
-1, -1, -1, -1, 2, 4, 6, 8
```

The 89-entry 15-bit step table for indices 0 through 88 is:

```
7, 8, 9, 10, 11, 12, 13, 14, 16, 17, 19, 21, 23, 25, 28, 31,
34, 37, 41, 45, 50, 55, 60, 66, 73, 80, 88, 97, 107, 118,
130, 143, 157, 173, 190, 209, 230, 253, 279, 307, 337, 371,
408, 449, 494, 544, 598, 658, 724, 796, 876, 963, 1060, 1166,
1282, 1411, 1552, 1707, 1878, 2066, 2272, 2499, 2749, 3024,
3327, 3660, 4026, 4428, 4871, 5358, 5894, 6484, 7132, 7845,
8630, 9493, 10442, 11487, 12635, 13899, 15289, 16818, 18500,
20350, 22385, 24623, 27086, 29794, 32767
```

Outputs reflect the current state and combinational encoding: `p_out=valpred`, `i_out=index`, `err=va_d-valpred`, `sz_out=step`, and `s_out` is the current difference sign.
